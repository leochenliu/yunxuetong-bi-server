# 驾驶舱图形化指标建议

本文整理培训业务驾驶舱的图表指标建议。这里是产品与分析口径建议，不代表所有指标已经在系统中实现。

## 设计原则

- 总览优先呈现当前值、与上一批次的变化，以及需要关注的异常。
- 只有定义清楚分母、去重方式和业务状态映射后，才将比率或漏斗指标作为正式口径。
- 区分「人数」「人次」「明细行数」：课程月度汇总表中的同一学员可能出现于多个课程或月份。
- 驾驶舱只展示汇总结果，不展示明文证件号码或手机号。
- 多类别图表应控制类别数量；单位等类别过多时展示 Top 10，其余合并为「其他」。

## 一、总览 KPI 卡片

当前 [metrics.yaml](../config/metrics.yaml) 已定义以下五项指标：

| 指标 | 建议展示 |
|---|---|
| 报名总人数 | 当前人数、较上一批次增减 |
| 已安排考试人数 | 人数及占报名人数比例；需先确认该比例口径 |
| 已通过人数 | 人数及通过率；需先明确通过率分母 |
| 平均分 | 当前平均分、较上一批次变化 |
| 已付款人数 | 人数及缴费率；需先确认缴费状态取值和口径 |

建议卡片同时显示「当前值 + 与上一批次变化」，避免只呈现静态数字。比例指标完成口径确认前，可先展示人数，不应把未经验证的比例作为业务事实。

## 二、报名规模与课程结构

| 指标 / 维度 | 建议图表 | 说明 |
|---|---|---|
| 按报名月份的报名人数 | 折线图 | 用于观察招生趋势和季节性 |
| 按**自然时间周期**的报名人数 | 折线图 | 周期口径由 `config/period.yaml` 配置（单位：天，`days=7` 是一周、`days=30` 是一个自然月）；页面显示当前周期天数与锚点 |
| 课程 × 月份报名情况 | 热力图或堆叠柱图 | 用于比较课程在不同月份的规模 |
| 各课程报名人数排名 | 横向条形图 | 课程较多时可只展示 Top N |
| 各课程月份的学员数 | 趋势图或对比图 | 标明统计的是「人数」还是「人次」 |

课程月度汇总表当前有 418 条明细行。同一学员可能出现在不同课程或月份，不能直接将明细行数解释为独立学员人数。计算人数时应按身份键去重，并与人次、明细行数分别命名。

## 三、培训与考试进度

建议先核实状态取值和阶段定义，再选择以下图表：

- **考试状态分布**：堆叠柱图或环形图。
- **已安排考试 / 未安排考试人数**：柱图或进度条。
- **各课程或班级的考试进度**：分组柱图。
- **补考次数分布**：柱图，例如 0 次、1 次、2 次及以上。
- **培训第一天与第二天签到情况**：分组柱图或完成率对比。
- **延期换证人数**：KPI 卡片，并可按月份或课程拆分。
- **培训到考试通过的阶段转化**：若报名、培训、考试、通过各阶段的定义和取值映射得到确认，可用漏斗图；确认前不建议直接推导阶段转化率。

## 四、成绩分析

- **分数区间人数**：柱状分布图，例如不及格、60–69、70–79、80–89、90 分以上；区间边界应由业务确认。
- **各课程通过率与平均分**：分组条形图；需明确分母及缺考、无分数的处理方式。
- **补考次数与成绩关系**：分组柱图。
- **低分人数、无分数人数**：质量提示卡片或异常概览。
- **平均分变化**：趋势图，并保留人数和有分数人数作为上下文，避免只看均值。

成绩分布可以补充平均分指标，帮助发现「平均分稳定，但低分或无分数人数变化」等情况。

## 五、缴费与开票

登高总表包含是否付款、金额、是否开票等字段；人员名单数据包含缴费情况。可评估以下图表：

- **已缴费 / 未缴费人数及比例**。
- **付款人数和付款金额**。
- **按课程或月份拆分的缴费状态**。
- **已付款但未开票人数**：须先确认两字段的状态值和业务关系。
- **已付款但金额为空或为 0 的记录数**：可作为异常提示。

在正式上线金额、缴费率或开票率前，应先检查实际取值，明确退款、部分付款、未知状态等情况如何处理。

## 六、人员画像

培训人员名单包含课程、年份、最高学历、职称等级、工作单位等字段，可考虑：

- **按课程 / 年份的人数**：柱图或趋势图。
- **学历结构**：条形图或环形图。
- **职称等级结构**：条形图。
- **参训人数最多的单位**：横向条形图，默认 Top 10，其余归为「其他」。
- **各单位参训人数对比**：支持按课程或年份筛选。

只展示聚合后的统计结果，不在图表、标签、提示框或导出内容中展示证件号码和手机号。

## 七、数据质量与业务异常

数据集配置中已有或覆盖的异常类型包括重复记录、证件号码校验、分数范围、通过但无考试日期、通过但分数过低、通过但无分数、已付款但金额为空或为 0 等。建议提供：

- **异常总数及较上一批次变化**：醒目的 KPI 卡片。
- **各异常规则数量排名**：横向条形图。
- **按批次的异常数量趋势**：折线图或堆叠柱图。
- **高严重度异常明细**：列表或表格，并可下钻到原始文件证据。

异常区域建议固定显示在驾驶舱中，确保用户在查看业务指标时也能判断数据可信度。

## 建议实施顺序

1. **第一阶段：总览**——现有五项核心 KPI、批次变化、异常概览。
2. **第二阶段：业务趋势**——课程月份、考试状态、成绩分布。
3. **第三阶段：运营分析**——缴费开票、人员画像；先核对字段实际值和计算口径。

目前 `course_monthly_summary` 只有 `20261015` 一个批次，可以先展示当前批次的课程 / 月份结构，暂不足以形成跨批次趋势。需后续持续导入同类批次，才能绘制可靠的历史趋势。
